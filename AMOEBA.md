# AMOEBA.md

## Repository Guidance

This repository is enabled for agent access and guidance.

## Project Rules

- Use TypeScript for all new files
- Follow existing code style
- Write tests for new features
- Ensure UI components are responsive

## Development Guidelines

### Change Management
- Make changes in small, incremental batches
- Wait for sync to complete before starting next batch
- Avoid editing more than 5-10 files at once
- Use git commits frequently (every 2-3 feature additions)

### Sync Settings
- If sync errors persist, disable Automatic Git sync temporarily
- Check PowerShell terminal for any ongoing processes before starting new tasks

Create these UI/UX skill documents in my skills/ folder. Do not touch any project source files.

1. **skills/UI_DESIGN_SYSTEM.md** – Component patterns, spacing, typography, color systems, responsive design
2. **skills/TAILWIND_PATTERNS.md** – Common Tailwind CSS patterns, utility-first approaches, responsive breakpoints
3. **skills/NEXTJS_UI_PATTERMS.md** – App Router patterns, server/client components, loading states, error boundaries
4. **skills/ANIMATION_PATTERNS.md** – GSAP and Lenis usage patterns, scroll animations, page transitions
5. **skills/ACCESSIBILITY.md** – ARIA labels, keyboard navigation, contrast ratios, semantic HTML
6. **skills/FORM_DESIGN.md** – Search bars, filters, dropdowns, input validation, feedback states

Base these on modern web design trends (2024-2025), Tailwind CSS v4, and Next.js App Router.
