# Cost-Reduction Workflows

## Token Efficiency
- Summarize before expanding
- Use smaller models for drafting
- Cache repetitive research
- Use Context7 for library docs instead of large prompts

## MCP Cost Saving
- Use filesystem MCP to store reusable snippets
- Use memory MCP to avoid re-explaining context
- Use brave-search + filesystem to build local knowledge base
- Avoid repeated web fetches

## Session Management
- Close idle sessions
- Consolidate related tasks
- Use sequential-thinking MCP for planning before execution
- Review token usage per session
