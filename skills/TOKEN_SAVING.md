# Token-Saving Techniques

## Prompt Optimization
- Use concise, targeted prompts
- Remove unnecessary context
- Reuse previous outputs via references
- Batch related requests together

## Context Management
- Summarize long conversations before continuing
- Use memory MCP for persistent facts
- Archive old threads
- Prune <think> tags where possible

## Best Practices
- Prefer specific instructions over open-ended
- Use system prompts to set boundaries once
- Limit examples to 3-5 per task
- Request structured output to reduce ambiguity
